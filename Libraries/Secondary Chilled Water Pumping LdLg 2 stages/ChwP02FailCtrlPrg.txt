'Pump fail with lockout

Numeric Input ChwP02Cmd, ChwP02Sts
Numeric Output ChwP02Falm
Numeric Public GraphicBtn

AlarmOff:
ChwP02Falm = Off
GraphicBtn = Off
If ChwP02Cmd = On and ChwP02Sts = Off Then Goto CheckStatus

CheckStatus:
GraphicBtn = Off
If (ChwP02Cmd = On and ChwP02Sts = On) or ChwP02Cmd = Off Then Goto AlarmOff
If TS > 120 Then Goto AlarmOn

AlarmOn:
ChwP02Falm = On
If GraphicBtn = On Then Goto AlarmReset

AlarmReset:
If TS > 3 Then GraphicBtn = Off
If TS > 6 Then Goto AlarmOff

E:
If TS > 30 Then Goto AlarmOff
