'SaFanAlmCtl - Supply Air Fan Alarm Control Program
'Built by Barbeau
'Version 2016-02-18 0825
'Set fan fail and fan in hand alarms

Numeric Input SaFanCmd, SaFanSts
Numeric Output SaFanFalm

Line WaitMode
  Set SaFanFalm to Off
  If SaFanCmd is On and SaFanSts is Off then Goto CheckStatus

Line CheckStatus
  If (SaFanCmd is On and SaFanSts is On) or SaFanCmd is Off then Goto WaitMode
  If TS >= 120 then Set SaFanFalm to On

Line E
  If TS >= 10 then Goto WaitMode
