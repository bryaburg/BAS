'ChlrFailTestPrg
'Built by Barbeau
'Version 2019-08-08 1537
'This program checks failure alarms and sets the correct failure flag.

Numeric Input Ch01Falm, Ch02Falm, ChlrLd, ChlrLg
Numeric Output ChLdFalm, ChLgFalm

Hold:
If TS > 2 then Goto FailCheck

FailCheck:
If ChlrLd is 1 and Ch01Falm is On then Set ChLdFalm to On
If ChlrLd is 1 and Ch01Falm is Off then Set ChLdFalm to Off
If ChlrLd is 2 and Ch02Falm is On then Set ChLdFalm to On
If ChlrLd is 2 and Ch02Falm is Off then Set ChLdFalm to Off

If ChlrLg is 1 and Ch01Falm is On then Set ChLgFalm to On
If ChlrLg is 1 and Ch01Falm is Off then Set ChLgFalm to Off
If ChlrLg is 2 and Ch02Falm is On then Set ChLgFalm to On
If ChlrLg is 2 and Ch02Falm is Off then Set ChLgFalm to Off
Goto Hold
