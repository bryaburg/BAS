'ChwP01CmdPrg
'Built by Barbeau
'Version 2020-09-29 1055
'This program controls Heating Water Loop Pump Start/Stop Command.

Numeric Input ChwPmpLd, ChwPmpLg, ChwPmpLdEna, ChwPmpLgEna, ChwPmpSpdSig, ChwP01Falm, MinSpdSpt
Numeric Output ChwP01Cmd, ChwP01Spd
Numeric RmpUp, RmpTm, StgDnSpd

ChwP01Cmd = 0
ChwP01Spd = 0

Init:
RmpUp = 5
RmpTm = 20
Goto CheckStatus

CheckStatus:
If ChwP01Cmd = On and ChwP01Spd > 0 and ChwP01Falm = Off Then Goto Modulating
Goto PumpOff

PumpOff:
ChwP01Spd = 0
ChwP01Cmd = Off
If ChwPmpLd = 1 and ChwPmpLdEna = On and ChwP01Falm = Off Then Goto Ramp
If ChwPmpLg = 1 and ChwPmpLgEna = On and ChwP01Falm = Off Then Goto Ramp

Ramp:
ChwP01Cmd = On
ChwP01Spd = Minimum(Maximum(MinSpdSpt,TS),ChwPmpSpdSig)
StgDnSpd = ChwPmpSpdSig
If ChwP01Falm = On Then Goto PumpOff
If ChwPmpLd = 1 and ChwPmpLdEna = Off Then Goto DelayOff
If ChwPmpLg = 1 and ChwPmpLgEna = Off Then Goto DelayOff
If TS > 100 Then Goto Modulating

Modulating:
ChwP01Cmd = On
ChwP01Spd = ChwPmpSpdSig
StgDnSpd = ChwPmpSpdSig
If ChwP01Falm = On Then Goto PumpOff
If ChwPmpLd = 1 and ChwPmpLdEna = Off Then Goto DelayOff
If ChwPmpLg = 1 and ChwPmpLgEna = Off Then Goto DelayOff

DelayOff:
ChwP01Cmd = On
ChwP01Spd = Maximum((StgDnSpd - TS), MinSpdSpt)
If ChwP01Falm = On Then Goto PumpOff
If ChwPmpLd = 1 and ChwPmpLdEna = On Then Goto Modulating
If ChwPmpLg = 1 and ChwPmpLgEna = On Then Goto Modulating
If TS > 20 Then Goto PumpOff

E:
If TS > 10 Then Goto PumpOff
