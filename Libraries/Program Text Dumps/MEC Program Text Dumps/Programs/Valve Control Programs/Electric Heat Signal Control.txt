'HtgCtl Program
'Built by Barbeau
'Version 2018-02-05 0852
'Modulates electric heat to maintain supply temp

Numeric Input SaFanSts, SaTmp, SaTmpSpt, HtgEna
Numeric Output EhStg
Numeric Lerr,Intg,Kp,Ki,Kd,Bias,Resptime
Function PidLoopFct

Line Shutdown
'Shut valve and initialize values
Set EhStg to 0.0
Set Lerr to 0.0
Set Intg to 0.0
Set Resptime to 3
If SaFanSts is On and SaTmp < SaTmpSpt - 2 and HtgEna is On then goto PIDSetup

Line PIDSetup
'Provide initial parameters for PID loop
Set Kp to 2.5 '50/20 Twenty degrees is the proportional band.
Set Ki to Kp/100 * Resptime
Set Kd to Ki/8
Set Bias to 5
Goto HeatMod

Line HeatMod
'Run PID loop function and assign result to heating percentage
Set EhStg to PidLoopFct(SaTmp,SaTmpSpt,Kp,Ki,Kd,Bias,0,Lerr,Intg)
Goto Checkerror

Line Checkerror
'Stays on this line if PID loop is close to set point.  
'Goes to shutdown if a parameter changes.
If abs(SaTmp - SaTmpSpt) >= 0.1 and TS>=Resptime then goto HeatMod
If SaFanSts is Off or SaTmp > SaTmpSpt + 10 or HtgEna is Off then Goto Shutdown

Line E
'Error: Only ends up on this line if the program has a major issue.
If TS>=10 then goto Shutdown
