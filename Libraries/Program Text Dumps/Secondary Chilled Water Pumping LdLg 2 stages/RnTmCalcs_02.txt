'Calculates run time

Numeric Input Blr02Sts
Numeric Public Blr02RnTm

StatusOff:
If Blr02Sts = On Then Goto StatusOn

StatusOn:
If TS > 5 Then Goto AddTime
If Blr02Sts = Off Then Goto StatusOff

AddTime:
Blr02RnTm = Blr02RnTm + (5/3600)
Goto StatusOn
