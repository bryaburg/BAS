'BlrFailTestPrg
'Built by Barbeau
'Version 2022-07-14 1456
'This program checks failure alarms and sets the correct failure flag.

Numeric Input Blr01Falm, Blr02Falm, BlrLd, BlrLg
Numeric Output LdBlrFalm, LgBlrFalm, FalmQty

Hold:
If TS > 2 Then Goto FailCheck

FailCheck:
If BlrLd = 1 and Blr01Falm = On Then LdBlrFalm = On
If BlrLd = 1 and Blr01Falm = Off Then LdBlrFalm = Off
If BlrLd = 2 and Blr02Falm = On Then LdBlrFalm = On
If BlrLd = 2 and Blr02Falm = Off Then LdBlrFalm = Off

If BlrLg = 1 and Blr01Falm = On Then LgBlrFalm = On
If BlrLg = 1 and Blr01Falm = Off Then LgBlrFalm = Off
If BlrLg = 2 and Blr02Falm = On Then LgBlrFalm = On
If BlrLg = 2 and Blr02Falm = Off Then LgBlrFalm = Off

FalmQty = LdBlrFalm + LgBlrFalm
Goto Hold
