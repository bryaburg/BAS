'Blr01FailCtrlPrg
'Built by Barbeau
'Version 2022-07-14 1456
'Boiler fail with lockout

Numeric Input Blr01Cmd, Blr01Sts
Numeric Output Blr01Falm
Numeric Public GraphicBtn

AlarmOff:
Blr01Falm = Off
GraphicBtn = Off
If Blr01Cmd = On and Blr01Sts = Off Then Goto CheckStatus

CheckStatus:
GraphicBtn = Off
If (Blr01Cmd = On and Blr01Sts = On) or Blr01Cmd = Off Then Goto AlarmOff
If TS > 120 Then Goto AlarmOn

AlarmOn:
Blr01Falm = On
If GraphicBtn = On Then Goto AlarmReset

AlarmReset:
If TS > 3 Then GraphicBtn = Off
If TS > 6 Then Goto AlarmOff
