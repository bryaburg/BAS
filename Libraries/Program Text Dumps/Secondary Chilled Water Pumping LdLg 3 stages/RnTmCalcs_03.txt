'Calculates run time

Numeric Input ChwP03Sts
Numeric Public ChwP03RnTm

StatusOff:
If ChwP03Sts = On Then Goto StatusOn

StatusOn:
If TS > 5 Then Goto AddTime
If ChwP03Sts = Off Then Goto StatusOff

AddTime:
ChwP03RnTm = ChwP03RnTm + (5/3600)
Goto StatusOn
