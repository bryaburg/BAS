' ============================================================================
' NOTE: SE script (EcoStruxure Building Operation) text-based language file.
'       Help/syntax reference: EcoStruxure Building Operation - Plain English
'       and Script Difference Guide, 04-40002-01-en (Dec 2021), Section 4
'       "Program Language Differences". Native delay/wait keyword is
'       "Wait <seconds>" (alias "Delay"); there is no literal "checkwait".
'       System constants: True, False, On, Off. System variables: Date,
'       Hour, Month, Year.
' ============================================================================
'
Numeric Input ChwSysCmd, ChwPmpLd, ChwPmpLg, ChwPmpLdEna, ChwPmpLgEna, ChwPmp02Falm, MechClgEna
Numeric Output ChwPmp02Cmd

Init:
 ChwPmp02Cmd = Off
 If TS > 5 and ChwSysCmd = On and MechClgEna = On Then Goto CheckStatus
 
CheckStatus:
 If ChwSysCmd = Off or MechClgEna = Off Then Goto Init
 Goto PumpOff
 
PumpOff:
 ChwPmp02Cmd = Off
 If ChwSysCmd = Off Then Goto Init
 If MechClgEna = Off Then Goto Init
 If ChwPmpLd = 2 and ChwPmpLdEna = On Then Goto PumpOn
 If ChwPmpLg = 2 and ChwPmpLgEna = On Then Goto PumpOn
 
PumpOn:
 ChwPmp02Cmd = On
 If ChwSysCmd = Off Then Goto Init
 If MechClgEna = Off Then Goto Init
 If ChwPmp02Falm = On Then Goto PumpOff
 If ChwPmpLd = 2 and ChwPmpLdEna = Off Then Goto PumpOff
 If ChwPmpLg = 2 and ChwPmpLgEna = Off Then Goto PumpOff
