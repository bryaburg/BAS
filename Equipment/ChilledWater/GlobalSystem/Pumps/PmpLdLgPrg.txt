'BlrLdLgPrg
'Built by Barbeau
'Version 2022-07-14 1456
'This program controls the Boiler Lead Lag Command.

Numeric Input SysEna, Stg, LdBlrFalm, LgBlrFalm
Numeric Output LdBlrEna, LgBlrEna

'CheckStatus:
'If LgBlrEna = On Then Goto Stage2
'If LdBlrEna = On Then Goto Stage1
'Goto Shutdown

Shutdown:
LdBlrEna = Off
LgBlrEna = Off
If SysEna = On and Stg > 0 Then Goto Stage1

Stage1:
LdBlrEna = On
LgBlrEna = Off
If SysEna = Off Then Goto DelayOff
If TS > 30 and (Stg > 1 or LdBlrFalm = On) Then Goto Stage2

Stage2:
LdBlrEna = On
LgBlrEna = On
If SysEna = Off Then Goto DelayOff
If TS > 30 and (Stg < 2 and LdBlrFalm = Off) Then Goto Stage1

DelayOff:
If SysEna = On Then Goto Stage1
If TS > 30 Then Goto Shutdown
