' ============================================================================
' NOTE: SE script (EcoStruxure Building Operation) text-based language file.
'       Help/syntax reference: EcoStruxure Building Operation - Plain English
'       and Script Difference Guide, 04-40002-01-en (Dec 2021), Section 4
'       "Program Language Differences". Native delay/wait keyword is
'       "Wait <seconds>" (alias "Delay"); there is no literal "checkwait".
'       System constants: True, False, On, Off. System variables: Date,
'       Hour, Month, Year.
' ============================================================================
'
Numeric Input ChwSysCmd, ChwPmpLd, ChwPmpLg, ChwPmpLdEna, ChwPmpLgEna, ChwPmp01Falm, MechClgEna
Numeric Output ChwPmp01Cmd

Init:
 ChwPmp01Cmd = Off
 If TS > 5 and ChwSysCmd = On and MechClgEna = On Then Goto CheckStatus
 
CheckStatus:
 If ChwSysCmd = Off Then Goto Init
 If ChwPmp01Cmd = On and ChwPmp01Falm = Off Then Goto PumpOn
 Goto PumpOff
 
PumpOff:
 ChwPmp01Cmd = Off
 If ChwSysCmd = Off Then Goto Init
 If MechClgEna = Off Then Goto Init
 If ChwPmp01Cmd = On and ChwPmp01Falm = Off Then Goto PumpOn
 If ChwPmpLd = 1 and ChwPmpLdEna = On Then Goto PumpOn
 If ChwPmpLg = 1 and ChwPmpLgEna = On Then Goto PumpOn
 
PumpOn:
 ChwPmp01Cmd = On
 If ChwSysCmd = Off Then Goto Init
 If MechClgEna = Off Then Goto Init
 If ChwPmp01Falm = On Then Goto PumpOff
 If ChwPmpLd = 1 and ChwPmpLdEna = Off Then Goto PumpOff
 If ChwPmpLg = 1 and ChwPmpLgEna = Off Then Goto PumpOff
