Numeric Input Blr02Cmd, Blr02Sts
Numeric Output Blr02Falm
Numeric Public GraphicBtn

AlarmOff:
Blr02Falm = Off
GraphicBtn = Off
If Blr02Cmd = On and Blr02Sts = Off Then Goto CheckStatus

CheckStatus:
GraphicBtn = Off
If (Blr02Cmd = On and Blr02Sts = On) or Blr02Cmd = Off Then Goto AlarmOff
If TS > 120 Then Goto AlarmOn

AlarmOn:
Blr02Falm = On
If GraphicBtn = On Then Goto AlarmReset

AlarmReset:
If TS > 3 Then GraphicBtn = Off
If TS > 6 Then Goto AlarmOff
