'Blr02CmdPrg

'This program controls Boiler Start/Stop Command.

Numeric Input Blr02Md, BlrLd, BlrLg, LdBlrEna, LgBlrEna, BlrSpdSig, Blr02Falm, MinSpdSpt
Numeric Output Blr02Cmd, Blr02Spd
Numeric RmpUp, RmpTm, StgDnSpd

Init:
RmpUp = 5
RmpTm = 20
Goto CheckStatus

CheckStatus:
If Blr02Cmd = On and Blr02Spd > 0 and Blr02Falm = Off and (Blr02Md = 1 or Blr02Md = 3) Then Goto Modulating
Goto BoilerOff

BoilerOff:
Blr02Spd = 0
Blr02Cmd = Off
If BlrLd = 2 and LdBlrEna = On and Blr02Falm = Off and Blr02Md = 3 Then Goto Ramp
If BlrLg = 2 and LgBlrEna = On and Blr02Falm = Off and Blr02Md = 3 Then Goto Ramp
If  Blr02Falm = Off and Blr02Md = 3 Then Goto Ramp
If Blr02Md = 1 Then Goto Ramp

Ramp:
Blr02Cmd = On
Blr02Spd = Minimum(Maximum(MinSpdSpt,TS),BlrSpdSig)
StgDnSpd = BlrSpdSig
If Blr02Falm = On or Blr02Md = 2 Then Goto BoilerOff
If BlrLd = 2 and LdBlrEna = Off and Blr02Md <> 1 Then Goto DelayOff
If BlrLg = 2 and LgBlrEna = Off and Blr02Md <> 1 Then Goto DelayOff
If TS > 100 Then Goto Modulating

Modulating:
Blr02Cmd = On
Blr02Spd = BlrSpdSig
StgDnSpd = BlrSpdSig
If Blr02Falm = On or Blr02Md = 2 Then Goto BoilerOff
If BlrLd = 2 and LdBlrEna = Off and Blr02Md <> 1 Then Goto DelayOff
If BlrLg = 2 and LgBlrEna = Off and Blr02Md <> 1 Then Goto DelayOff

DelayOff:
Blr02Cmd = On
Blr02Spd = Maximum((StgDnSpd - TS), MinSpdSpt)
If Blr02Falm = On or Blr02Md = 2 Then Goto BoilerOff
If BlrLd = 2 and LdBlrEna = On and (Blr02Md = 1 or Blr02Md = 3) Then Goto Modulating
If BlrLg = 2 and LgBlrEna = On and (Blr02Md = 1 or Blr02Md = 3) Then Goto Modulating
If TS > 20 Then Goto BoilerOff

E:
If TS > 10 Then Goto BoilerOff
