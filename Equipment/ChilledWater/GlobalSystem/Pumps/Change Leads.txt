'ChangeLeads 
'Built by Barbeau
'Version 2022-07-14 1456
'Changes leads based upon input 

Numeric Input ChgLd, Blr01RnTm, Blr02RnTm
Numeric Output BlrLd, BlrLg
String Output Seq
Numeric Public Sts12, Sts21
Numeric Public Btn12, Btn21 

Run12:
Sts12 = On
Sts21 = Off
If Btn12 = On Then Goto Set12
If Btn21 = On Then Goto Set21
BlrLd = 1
BlrLg = 2
Seq = "12"
If TS > 30 and ChgLd = On and Blr01RnTm < Blr02RnTm Then Goto Set12
If TS > 30 and ChgLd = On and Blr02RnTm < Blr01RnTm Then Goto Set21

Run21:
Sts12 = Off
Sts21 = On
If Btn12 = On Then Goto Set12
If Btn21 = On Then Goto Set21
BlrLd = 2
BlrLg = 1
Seq = "21"
If TS > 30 and ChgLd = On and Blr01RnTm < Blr02RnTm Then Goto Set12
If TS > 30 and ChgLd = On and Blr02RnTm < Blr01RnTm Then Goto Set21

Set12:
Btn12 = Off
Btn21 = Off
Goto Run12

Set21:
Btn12 = Off
Btn21 = Off
Goto Run21
