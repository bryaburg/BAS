' ============================================================================
' NOTE: SE script (EcoStruxure Building Operation) text-based language file.
'       Help/syntax reference: EcoStruxure Building Operation - Plain English
'       and Script Difference Guide, 04-40002-01-en (Dec 2021), Section 4
'       "Program Language Differences". Native delay/wait keyword is
'       "Wait <seconds>" (alias "Delay"); there is no literal "checkwait".
'       System constants: True, False, On, Off. System variables: Date,
'       Hour, Month, Year.
' ============================================================================
'
Numeric Input ChwSysCmd, ChwPmpLdFalm, ChwPmpLgFalm, MechClg
Numeric Output ChwPmpLdEna, ChwPmpLgEna

ShutDown:
 ChwPmpLdEna = Off
 ChwPmpLgEna = Off
 If ChwSysCmd = On and MechClg = On Then Goto LeadOn
 
LeadOn:
 ChwPmpLdEna = On
 ChwPmpLgEna = Off
 If ChwSysCmd = Off or MechClg = Off Then Goto Shutdown
 If TS > 30 and ChwPmpLdFalm = On Then Goto LagOn
 
LagOn:
 ChwPmpLdEna = Off
 ChwPmpLgEna = On
 If ChwSysCmd = Off or MechClg = Off Then Goto Shutdown
 If TS > 30 and ChwPmpLdFalm = Off Then Goto LeadOn
