'SaTmpSptCtrl
'Built by Barbeau
'Version 2020-11-11 0751
'Controls supply temp setpoint based upon room temp

Numeric Input SaFanSts, RmTmp, RmTmpSpt, SaTmpMinSpt, SaTmpMaxSpt
Numeric Output SaTmpSpt, HtgClgDmd
Function PIDfct
Numeric Lerr,Intg,ResetRatio


CalculateOff:
  SaTmpSpt = RmTmp
  If SaFanSts = On Then Goto CalculateOn

CalculateOn:
  HtgClgDmd = PIDfct(RmTmp,RmTmpSpt,5,0.15,0.01875,50,1,Lerr,Intg)
  Goto UpdateStats

UpdateStats:
  ResetRatio = (SaTmpMaxSpt-SaTmpMinSpt)/100
  SaTmpSpt = SaTmpMaxSpt -( ResetRatio * HtgClgDmd)
  If TS > 3 and abs(RmTmp-RmTmpSpt) > 0.1 then Goto CalculateOn
  If TS > 3 and SaFanSts = Off Then Goto CalculateOff

Line E
  If TS > 10 then Goto CalculateOff
