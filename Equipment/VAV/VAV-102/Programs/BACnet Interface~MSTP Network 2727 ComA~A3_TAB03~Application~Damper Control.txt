Numeric Input MaxCFM,MinCFM,ReheatCFM,AhuFanStatus,AvgAirFlow,HeatCoolDemand,VavPressurize,ReheatEnable,HWAvailable,VavStaticErrorSP
Numeric Output AirflowSetpoint,Damper,AirFlowPerCentSP
Function PidLoop
Numeric Kp,Ki,Kd,Lerr,Intg,Resptime'Function Arguments
Numeric Runtime'Belimo Damper Actuator Travel Time (SECONDS) 
Numeric DamperFeedback,DamperError,DamperSet,RatioMult,ResetPerCent,ReheatBoost,Bias

Line Shutdown
  Set AirflowSetpoint to MinCFM
  Set AirflowPerCentSP to 0
  Set Damper to 0
  Set Runtime to 180
  Set Resptime to 3
  If MaxCFM>=3000 then Set Kp to 0.01
  If MaxCFM>=2500 and MaxCFM < 3000 then Set Kp to 0.015
  If MaxCFM>=1500 and MaxCFM < 2500 then Set Kp to 0.02
  If MaxCFM>=1000 and MaxCFM < 1500 then Set Kp to 0.05
  If MaxCFM>=500 and MaxCFM < 1000 then Set Kp to 0.05
  If MaxCFM>=250 and MaxCFM < 500 then Set Kp to 0.05
  If MaxCFM<250 then Set Kp to 0.05
  Set Ki to(Kp/50)*Resptime
  Set Kd to(Ki/8)
  Set Lerr to 0
  Set Intg to 0
  If AhuFanStatus is On then Goto AirflowCheck

Line AirflowCheck
  If AhuFanStatus is Off then Goto Shutdown
  If MinCFM<=1 then Set MinCFM to 1
  If ReheatCFM<=1 then Set ReheatCFM to 1
  Set ReheatBoost to(ReheatCFM-MinCFM)
  If ReheatBoost<=1 then Set ReheatBoost to 0.01
  Set RatioMult to (MaxCFM-MinCFM)/MaxCFM
  If RatioMult is 0 then Set RatioMult to 0.01
  Set ResetPerCent to (100-ReheatEnable)/RatioMult
  If AirflowSetpoint>=MaxCFM *.5 then set AirflowPerCentSP to (AvgAirFlow/AirflowSetpoint)*100 else Set AirFlowPerCentSP to VavStaticErrorSP
  If VavPressurize is On then Set AirflowSetpoint to MaxCFM
  If VavPressurize is Off then
    If HeatCoolDemand>ReheatEnable then Set AirflowSetpoint to MaxCFM*(HeatCoolDemand-ReheatEnable)/ResetPerCent+MinCFM
    If HeatCoolDemand<=ReheatEnable and HWAvailable is On then Set AirflowSetpoint to MinCFM+(ReheatBoost-(HeatCoolDemand/ReheatEnable)*ReheatBoost)
    If HeatCoolDemand<=ReheatEnable and HWAvailable is Off then Set AirflowSetpoint to MinCFM
  Endif
  If abs(AvgAirflow-AirflowSetpoint)>=maximum((AirflowSetpoint*0.01),10) and TS>=Resptime then Goto ErrorCalc

Line ErrorCalc
  If AirflowSetpoint>=MaxCFM *.5 then set AirflowPerCentSP to (AvgAirFlow/AirflowSetpoint)*100 else Set AirFlowPerCentSP to VavStaticErrorSP
  Set DamperError to PIDLoop(AvgAirflow,AirflowSetpoint,Kp,Ki,Kd,Bias,0,Lerr,Intg)
  Goto ErrorCheck

Line ErrorCheck
  If DamperError is 0 or DamperError is 100 then Goto DamperPulse
  If abs(DamperSet-DamperError)<=100/Runtime then Goto AirflowCheck
  Goto DamperPulse

Line DamperPulse
  If ((DamperError>0) and (DamperError<100)) then
    Set Damper to (DamperError-DamperSet)
  Else
    If (DamperError is 0) then Set Damper to -(100/Runtime)
    If (DamperError is 100) then Set Damper to (100/Runtime)
  Endif
  Set DamperFeedback to (Damper*(100/Runtime))
  Set DamperSet to (maximum(minimum((DamperSet+DamperFeedback),100),0))
  Goto DamperCmdWait

Line DamperCmdWait
  If AirflowSetpoint>=MaxCFM *.5 then set AirflowPerCentSP to (AvgAirFlow/AirflowSetpoint)*100 else Set AirFlowPerCentSP to VavStaticErrorSP
  If TS>=abs(Damper)or TS>=Runtime then
    Set Damper to 0
    Goto AirflowCheck
  Endif

Line E
  If TS>=10 then Goto Shutdown
