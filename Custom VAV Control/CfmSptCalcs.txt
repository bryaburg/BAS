'CfmSptCalcs
'Built by Barbeau
'Version 2023-06-06 1735
'Calculates setpoint based upon mode
'Heat Cool Demand must go below HtgBias to enter heating ramp
'Heat Cool Demand must go above ClgBias to enter cooling ramp

Numeric Input ClgMaxCFM, ClgMinCFM, HtgMaxCFM ,HtgMinCFM, HwAvail, HtgBias, ClgBias
Numeric Input HtgClgDmd, AhuSts
Numeric Output CfmSpt
Function ResetFct

CalcOff:
  CfmSpt = ClgMinCFM
  If AhuSts = On Then Goto ZeroBand

ZeroBand:
  CfmSpt = ClgMinCFM
  If HtgClgDmd > ClgBias Then Goto ClgBias
  If HtgClgDmd < HtgBias Then Goto HtgBias

HtgBias:
  If HwAvail = On Then CfmSpt = ResetFct(HtgMaxCFM, HtgMinCFM, HtgBias, 0, 0, HtgClgDmd) Else CfmSpt = HtgMinCFM
  If HtgClgDmd > HtgBias Then Goto ZeroBand
  If AhuSts = Off Then Goto CalcOff

ClgBias:
  CfmSpt = ResetFct(ClgMaxCFM, ClgMinCFM, 100, ClgBias, 1, HtgClgDmd)
  If HtgClgDmd < ClgBias Then Goto ZeroBand
  If AhuSts = Off Then Goto CalcOff
