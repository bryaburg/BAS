'SaTmpSptCtrl
'Built by Barbeau
'Version 2023-06-05 1610
'Controls supply temp setpoint based upon room temp

Numeric Input AhuSts, AhuSaTmp, RmTmp, RmTmpSpt, SaTmpMinSpt, SaTmpMaxSpt, HwAvail, HtgBias
Numeric Output SaTmpSpt, HtgClgDmd, HtgEna
Function PIDfct
Numeric Lerr,Intg,ResetRatio

CalculateOff:
  SaTmpSpt = AhuSaTmp
  HtgClgDmd = 50
  If AhuSts = On Then Goto CalculateOn

CalculateOn:
  HtgClgDmd = PIDfct(RmTmp,RmTmpSpt,5,0.15,0.01875,50,1,Lerr,Intg)
  Goto UpdateStats

UpdateStats:
  ResetRatio = (SaTmpMaxSpt-SaTmpMinSpt)/100
  If HtgClgDmd < HtgBias and HwAvail = On Then HtgEna = On Else HtgEna = Off
  If HtgEna = On Then
    SaTmpSpt = SaTmpMaxSpt -( ResetRatio * HtgClgDmd)
  Else
    SaTmpSpt = AhuSaTmp
  Endif
  If TS > 3 and abs(RmTmp-RmTmpSpt) > 0.1 then Goto CalculateOn
  If AhuSts = Off Then Goto CalculateOff
