Numeric Input ChwSysCmd, ChwPmpLd, ChwPmpLg, ChwPmpLdEna, ChwPmpLgEna, ChwPmp02Falm, MechClgEna
Numeric Output ChwPmp02Cmd
Numeric UnitID

Init:
  UnitID = ???	'Set this to match the ID of the unit this is controlling
  Goto PumpOff
 
PumpOff:
   ChwPmp02Cmd = Off
   If ChwSysCmd = Off Then Goto Init
   If MechClgEna = Off Then Goto Init
   If ChwPmpLd = UnitID and ChwPmpLdEna = On and ChwSysCmd = On and MechClgEna = On Then Goto PumpOn
   If ChwPmpLg = UnitID and ChwPmpLgEna = On and ChwSysCmd = On and MechClgEna = On Then Goto PumpOn
 
PumpOn:
  ChwPmp02Cmd = On
  If (ChwPmpLd = UnitID and ChwPmpLdEna = Off) or ChwSysCmd = Off or MechClgEna = Off Then Goto DelayOff
  If (ChwPmpLg = UnitID and ChwPmpLgEna = Off) or ChwSysCmd = Off or MechClgEna = Off Then Goto DelayOff

DelayOff:
  If ChwPmpLd = UnitID and ChwPmpLdEna = On and ChwSysCmd = On and MechClgEna = On Then Goto PumpOn
  If ChwPmpLg = UnitID and ChwPmpLgEna = On and ChwSysCmd = On and MechClgEna = On Then Goto PumpOn
  If TS > 600 then Goto PumpOff
