'ChwP02CmdPrg
'Built by Barbeau
'Version 2020-09-29 1055
'This program controls Heating Water Loop Pump Start/Stop Command.

Numeric Input ChwPmpLd, ChwPmpLg, ChwPmpLdEna, ChwPmpLgEna, ChwPmpSpdSig, ChwP02Falm, MinSpdSpt
Numeric Output ChwP02Cmd, ChwP02Spd
Numeric RmpUp, RmpTm, StgDnSpd

ChwP02Cmd = 0
ChwP02Spd = 0

Init:
RmpUp = 5
RmpTm = 20
Goto CheckStatus

CheckStatus:
If ChwP02Cmd = On and ChwP02Spd > 0 and ChwP02Falm = Off Then Goto Modulating
Goto PumpOff

PumpOff:
ChwP02Spd = 0
ChwP02Cmd = Off
If ChwPmpLd = 2 and ChwPmpLdEna = On and ChwP02Falm = Off Then Goto Ramp
If ChwPmpLg = 2 and ChwPmpLgEna = On and ChwP02Falm = Off Then Goto Ramp

Ramp:
ChwP02Cmd = On
ChwP02Spd = Minimum(Maximum(MinSpdSpt,TS),ChwPmpSpdSig)
StgDnSpd = ChwPmpSpdSig
If ChwP02Falm = On Then Goto PumpOff
If ChwPmpLd = 2 and ChwPmpLdEna = Off Then Goto DelayOff
If ChwPmpLg = 2 and ChwPmpLgEna = Off Then Goto DelayOff
If TS > 100 Then Goto Modulating

Modulating:
ChwP02Cmd = On
ChwP02Spd = ChwPmpSpdSig
StgDnSpd = ChwPmpSpdSig
If ChwP02Falm = On Then Goto PumpOff
If ChwPmpLd = 2 and ChwPmpLdEna = Off Then Goto DelayOff
If ChwPmpLg = 2 and ChwPmpLgEna = Off Then Goto DelayOff

DelayOff:
ChwP02Cmd = On
ChwP02Spd = Maximum((StgDnSpd - TS), MinSpdSpt)
If ChwP02Falm = On Then Goto PumpOff
If ChwPmpLd = 2 and ChwPmpLdEna = On Then Goto Modulating
If ChwPmpLg = 2 and ChwPmpLgEna = On Then Goto Modulating
If TS > 20 Then Goto PumpOff

E:
If TS > 10 Then Goto PumpOff
